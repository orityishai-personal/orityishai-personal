# Orit links
Small, responsive Hebrew RTL link page. No framework, dependencies or build required.

## Edit
- `config.js`: WhatsApp (international format, e.g. 972...), email, Instagram and course URLs. Empty links are hidden.
- `index.html`: copy, service details and styles.
Contact details were intentionally left empty rather than guessing personal information.

## Preview
Run `python -m http.server 8000` from this folder, then open http://localhost:8000.

## Deploy
Import this repository as a separate Vercel project. Framework: Other. No build command. Output directory: `.`.
The project does not need environment variables or a paid backend.
Deployment and domain changes are not performed by this commit.

Note: the repository name matches the GitHub username, so this README may also appear on your GitHub profile. The application itself is a regular website.
