SEO READY SITE
==============

הקבצים כוללים:
- sitemap.xml
- robots.txt
- canonical בכל עמוד
- Open Graph + Twitter Card בכל עמוד
- Schema.org / JSON-LD
- 5 תמונות Open Graph בגודל 1200x630

חשוב לפני העלאה:
1. בצעי Search & Replace בכל התיקייה:
   https://YOUR-DOMAIN.com
   החליפי בכתובת האמיתית של האתר, למשל:
   https://example.com
   או זמנית:
   https://orityishai.vercel.app/

2. אם את עוברת בהמשך מדומיין Vercel לדומיין משלך, החליפי שוב את כתובת הבסיס
   בכל הקבצים וגם ב-sitemap.xml וב-robots.txt.

3. אחרי העלאה:
   - פתחי /robots.txt ובדקי שהוא נגיש
   - פתחי /sitemap.xml ובדקי שהוא נגיש
   - הוסיפי את האתר ל-Google Search Console
   - שלחי את sitemap.xml דרך Search Console
